ATS Checker 5 Q&A

ATS (Applicant Tracking System) is software used by 98% of large companies to automatically screen resumes before a human ever sees them. 🤖 Your ATS score (0-100) measures how well your resume is optimized. Above 75 = likely to pass through. Below 60 = might get filtered out even if you're qualified!

PDF, JPG, and PNG files up to 10MB. PDF is recommended as it preserves formatting. The file must be an actual resume — if you upload a random image, the system detects it and shows an error (with a cute robot animation 😄). Photos of resumes (JPG/PNG) also work!

No! Your resume file is analyzed in real-time and immediately discarded. 🔒 We never store your resume on any server. Only the score result and analysis are temporarily used to display your results page. Your privacy is our priority.

After scanning, you'll see specific missing keywords and suggestions. Key improvements: ① Use standard headings (Work Experience, Education, Skills). ② Copy exact keywords from the job description. ③ Avoid tables, graphics, and columns. ④ Save as PDF from Word/Google Docs (not Canva). ⑤ Include quantifiable achievements. 🎯

Common reasons: ① File isn't a resume. ② File exceeds 10MB — compress it. ③ Wrong format (only PDF/JPG/PNG). ④ Backend server not running — start with node server.js. ⑤ No Gemini API key set — add it at the Settings page. 🔧

AI Resume Writer 4 Q&A

Two modes! ✨ Bullet Points: describe what you did → AI generates 5 powerful professional bullets. Full Resume: describe yourself in a paragraph → AI creates a complete resume with all fields auto-filled in the Builder. Both are powered by Google Gemini AI.

The AI works by analyzing the user’s resume in detail. It evaluates different aspects such as content quality, structure, keywords, and formatting. Based on this analysis, it provides a rating and an ATS (Applicant Tracking System) score, similar to how an ATS checker reviews resumes. This helps users understand how well their resume is optimized for job applications and where improvements can be made.

For Bullet Points: click "Accept" → saved locally → click "Open in Resume Builder" to use. 🔄 For Full Resume: click "Open in Resume Builder →" and ALL fields auto-fill automatically — name, email, experience, skills, everything! You just review and download.
